HouseHub

Local home integration and energy monitoring project

About HouseHub

HouseHub is a private open-source home integration project running locally on a Raspberry Pi.

The goal is to collect and analyse technical and energy-related data from different systems while keeping the core system local and transparent.

Current integrations

  • Fronius photovoltaic system and battery
  • Vaillant heating system via local EEBUS
  • Ksenia security system monitoring

Planned integrations

  • Home Connect appliances
  • Weather and photovoltaic forecasts
  • Energy usage analysis and recommendations

Privacy and design

HouseHub is designed as a local-first system. Sensitive credentials and private household data are not published in this repository.

Home Connect integration is intended primarily for read-only monitoring, data collection and energy analysis.
